# 新增唐诗证据与标注规范 v1

## 目的

为新增130首诗补充主题、意象、颜色、表现手法和创作年代，同时保持“原文—依据—标注—统计”可追溯。候选标注和 Codex 辅助复核结果都不等同于文学史定论；在完成双人复核前，主表和来源仍保留各自的 `pending` 状态。

当前阶段真人复核不是内部可视化开发的阻塞条件。`approved` 仅表示该条记录已具备可定位的原文和来源依据，可以进入内部探索统计；不把它解释为专家终审或唯一文学结论。`pending` 表示项目审核状态尚未关闭，比赛提交或对外发布前再对争议项抽样复核。

历史分期采用 `period` 作为分析分组，精确年份只在有作品专属系年依据时填写 `year_start`/`year_end`。作者常用文学时段可以支持分组，但不得伪装成单篇作品的精确年份。

## 来源等级

| 等级 | 可作为依据的来源 | 用法 |
| --- | --- | --- |
| A | 校注本、学术论文、CSSN 等学术机构文章、大学正式课程材料 | 可支持断代、异文和文学解释；必须写出定位或说明争议 |
| B | 人民教育出版社、教育部项目、大学出版社的经典资源 | 可支持通行文本和教材中的常见解读；不能单独证明有争议的创作年份 |
| C | Chinese Text Project、Chinese Poetry 等开放数据库 | 用于原文、题名、作者和候选发现；需用 A/B 来源复核 |
| D | 普通诗词网站、搜索摘要、百科转载 | 只能作为线索，不得作为唯一依据或直接标记为专家结论 |

## 标注规则

1. **主题**：允许多标签；依据题材、语义和上下文，不把标题关键词直接当作定论。
2. **意象**：保留标准名、原文词形、句号、字符偏移和上下文。单字命中（如“日”“白”“关”）默认是候选，需人工判断是否为意象。
3. **颜色**：只记录颜色词面；`normalized_color` 只是展示归类，不代表古代色彩的精确色值。借代、姓氏、金属和地名均标为 `ambiguous`，不自动赋色值。
4. **表现手法**：优先记录有明确文本证据的比喻、拟人、夸张、对比、用典、衬托、借景抒情和托物言志。无法定位到单句时可以使用 `scope=poem`，但必须说明“候选解释”。
5. **创作年代**：只有存在明确年谱、题下注、历史事件或多来源一致意见时才填写 `year_start/year_end`。约数使用范围；争议或只有作者生卒年时留空。
6. **专家评价**：只能记录来源明确表达的评价或本项目对来源的转述；不能把模型推断写成专家原话。没有逐篇专家评价时，登记为“项目文本分析候选”。

## 当前批次的状态

`reports/tang_poem_evidence_register_v1.csv` 是原始候选登记表；`reports/tang_poem_evidence_register_v2.csv` 是新增130首辅助复核后的版本，包含 1306 条逐条决定。当前 `approved` 仅表示可进入项目内部探索统计，`needs_revision` 和 `rejected` 不进入确认统计；任何版本都不应在论文或比赛材料中写成“已完成专家认证”。

## 参考来源

- 中国哲学书电子化计划《全唐诗》与《唐诗别裁集》：文本和传统选本线索。
- 人民教育出版社“中华经典资源库”：教材通行本与经典诵读材料。
- 中国社会科学网“论杜诗系年的版本依据与标准”：创作年代需要年谱、编年本和版本依据，不能只凭单一网站。
- 中国社会科学网“数字人文在古代文学研究中的初步实践及学术意义”：逐篇记录年代、地点和证据链的研究方法。
- 北京大学相关月亮意象材料、陕西师范大学“唐诗与长安的双向建构”：意象和文学地理的解释参考。
