# 字段说明

以 schema.json 为唯一机器可读定义；Excel 数据字典为可阅读快照。修改设计应同步三者。空字段表示未知或不适用，不以0代替未知年份/坐标。

## poems（诗作）

|字段|含义|类型|必填|外键|枚举/规则|
|---|---|---|---|---|---|
|poem_id|稳定标识符|id|是||^poem_[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$；不可更改或复用|
|title|题名|text|是|||
|poet_id|关联 poets|id|是|poets|前缀_小写UUID；创建后不变，不按行号或名称生成|
|poetic_form|诗体|text|是||五言绝句 / 七言绝句 / 五言律诗 / 七言律诗 / 五言排律 / 七言排律 / 五言古诗 / 七言古诗 / 杂言古诗 / 其他 / 待考|
|yuefu_type|乐府属性|text|是||乐府 / 非乐府 / 待考|
|period|分期（初唐/盛唐/中唐/晚唐/待考）|text|否|||
|year_start|创作时间下界（公元年）|integer|否|||
|year_end|创作时间上界（公元年）|integer|否|||
|dating_basis|断代依据|text|否|||
|full_text|选定底本文字；以LF分句，无末尾换行|text|是|||
|variant_notes|异文说明；改底本需重审相关标注|text|否|||
|source_id|关联 sources|id|是|sources|前缀_小写UUID；创建后不变，不按行号或名称生成|
|source_locator|卷/页/条目/段落定位|text|是|||
|review_status|当前审核状态|text|是||draft / pending / approved / rejected / needs_revision|
|created_by|录入/标注人|text|是|||
|created_at|创建时间，带时区 ISO8601|datetime|是|||
|updated_at|修改时间，带时区 ISO8601|datetime|是|||
|notes|备注/争议|text|否|||
