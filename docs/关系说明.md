# 关系与录入口径

poets → poems → poem_lines 是主体。poem_tags 关联 tags；poem_imagery 关联 imagery；poem_places 关联 places；poet_schools 关联 category=school 的 tags；technique_annotations 关联 category=technique 的 tags。以上关联表使用独立主键，支持多标签、多出处与争议观点。poet_relations 是有向边。annotation_reviews 以 target_table + target_id 指向记录，并固定被审 updated_at 版本。sources 是统一书目来源。

## 标注范围

- poem：整诗；两个 line_id、两个 offset、quote 都留空，解释写明全诗层面的依据。
- line：单句；start_line_id=end_line_id，quote 必须等于整句，offset 均空。
- span：单句或连续跨句；两个 line_id 与 offset、quote 均必填。offset 按 Python Unicode 码点计数，0基、左闭右开，含原文标点。跨句时引文为起句后缀 + 中间整句 + 止句前缀，句间 LF。
- 意象、表现手法、颜色必须到 line 或 span；其他关联可为整诗。多处不连续出现需分行录入。
- line_no 从1连续且唯一；full_text 必须等于按 line_no 拼接的 line_text（LF 分隔）；每个 poems 行表示一个选定底本/版本。若版本不同，建立不同 poem_id，以 notes 标记同作关系；不要把异文混进同一文本。
- 任何底本文字、句序或标注变化均需更新 updated_at，review_status 改 pending；历史审核行追加保留。approved 必须有该版本最新审核 approved，且不得早于记录版本时间。
- poem_tags 允许多条相同标签的不同位置/来源。theme 为主题，emotion 为情感，poetic_form 专门表示诗体；乐府单列属性。流派通过 school 标签，勿当作作者唯一身份。
- 地理坐标是 WGS84，可空；古今对应、旅行或写作地点不确定时明确记录证据与争议。
- source_locator 只表示在关联来源中的定位；不可用虚构页码补齐。不确定事实保留 draft/pending。
- confidence 是标注者信心，不等于事实概率；非实义颜色需明确 usage_type。
