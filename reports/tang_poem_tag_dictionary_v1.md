# 唐诗标签词典规则说明 v1

## `pending` 的准确含义

此前 `tags.csv` 中的10条 `pending` 是**词典级状态**，不是150首诗的逐条标注状态。它们本轮已补齐纳入边界、排除边界和参考来源，并写入 `annotation_reviews.csv`；当前10条已改为 `approved`。这里的 `approved` 只表示项目规则已确认，不表示每首诗的标签都经过专家终审。当前阶段不把真人审核作为开发阻塞；逐诗标签仍须保留原文片段和解释。

## 规则表

| 标签 | 纳入条件 | 排除/谨慎条件 |
|---|---|---|
| 借景抒情 | 景物描写与当前引句中的情绪、处境或抒情转折有直接联系 | 只有景物罗列、没有可定位情感链条时不标 |
| 咏物 | 以一个具体物象为主要吟咏对象，并借其寄托品格、身世或情感 | 物象只是背景或普通名词出现时不标 |
| 夸张 | 数量、空间、时间、力量等被有意超常化，且不是字面纪实 | 普通程度副词和惯用语不能自动算夸张 |
| 对比 | 相反、相异、今昔、得失或动静两面被并置并形成张力 | 仅有两个并列景物而无对置关系时不标 |
| 托物言志 | 物象与作者品格、志向或身世存在可解释的对应关系 | 仅写物色、物态而无寄托依据时不标 |
| 拟人 | 非人事物被赋予人的动作、情感、意志或身份 | 传统拟声、通假和普通动词不能自动算拟人 |
| 比喻 | 存在本体、喻体及相似点，明喻或暗喻结构可在引句定位 | 单纯夸张、借代、拟人或通感不能混标为比喻 |
| 爱情闺怨 | 文本以爱情、宫怨、闺思或思妇处境为明确题材 | 只有“愁”“独”等泛化情绪时不标 |
| 用典 | 可追溯到历史、神话、经典或前代诗文的语境借用 | 普通常识词和无法定位典源的相似表达暂不标 |
| 衬托 | 通过动静、声静、景情或主次关系突出目标对象/情绪 | 仅有并列或顺承描写而无突出关系时不标 |

## 记录方式

逐诗标注仍使用 `poem_tags.csv` 或 `technique_annotations.csv`：一条标签一行，`scope`、`start_line_id`、`end_line_id`、`quote` 和 `explanation` 必须能回到原文。`approved` 表示当前证据足以进入项目内部统计；`rejected` 表示撤出该条候选，不代表整首诗没有其他解释。
