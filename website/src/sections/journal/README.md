# 诗词日志 · 四模块版

挂载于长卷 `#craft`。所有组件、数据、日期运算和 CSS 限定在本目录，不修改其他章节、公共导航和真实数据源。

## 上传与替换

当前题材采用用户提供的统计表，TCCP数据仅作为历史对照；排行采用汉语典，并于2026-10-21重新检索核对。五位榜单诗人的人物档案、代表作品与年谱均已接入有出处资料，详见 `artifacts/journal-research-20261021/README.md`。

- `tccpThemes` 保留原始九类数量；`journalThemes` 先合并山水田园，再将低于10%的题材归入其他，得到六类展示。计数自动换算为样本占比，外圈标签沿圆弧排列，圆心使用正文小字。
- `themeArtwork.ts`：六个扇区共用处理后视频的首帧 `theme-motion-poster.png`，统一坐标为 `(-200, -200, 400, 400)`，外圆半径175；SVG按真实统计数量裁出六个区域，外围文字及中央文字由网页绘制。原有插画素材保留。
- `ThemeMotion.tsx`：六个扇区共用一个按需加载的播放器。悬浮100毫秒或键盘聚焦后静音播放当前扇区；点击/Enter/Space可切换或停止，切换扇区从头播放。移出、离开视口、页面隐藏及导航时停止；加载/播放失败保留封面。减少动态效果时禁用悬浮播放，仍允许显式点击。视口检测观察HTML容器，避免Chromium在SVG遮罩变化时误报不可见。
- 新视频由用户提供的720×720、24fps、361帧完整六分区动画处理而来，不按题材切割时间轴。`scripts/prepare-theme-motion.py INPUT.mp4` 仅使用固定外圈及标签的SIFT/RANSAC特征估计整幅画面的统一相似变换，再经9帧中值及25帧高斯平滑；禁止使用扇区内人物、马匹、船只等动态内容独立估计缩放/旋转，避免误匹配造成局部变形和帧间跳动。缺失参数插值恢复，异常值被拒绝，并在相邻帧校正位移超过0.5源像素时阻止输出。本次361帧最大校正位移为0.0125源像素以内。去除音轨，用12帧融合衔接首尾；输出400×400、349帧、约14.54秒的 `theme-motion-stable.mp4`，新文件名避免浏览器复用旧视频缓存。封面与视频首帧一致；参数见 `src/assets/journal/theme-motion.json`。运行脚本需Python及av、opencv-python-headless、Pillow；配准回归测试：`python -m unittest discover -s scripts -p test_theme_registration.py`。旧的 `ThemeVideo.tsx` / `farewellVideo.ts` 为历史送别素材实现，当前圆环不再引用。
- `journalPeriods`：据林庚《盛唐气象》（1958）的四期作品约数：初唐2,757、盛唐6,341、中唐19,020、晚唐14,744首。不含五代及生平不明作家，不是逐年创作量。折线从0起算、上限20,000，使用直线连接并标出四个数值；来源保存在 `journalPeriodSource`。代表诗人保留交互，画像仍待补充。
- `journalPeriodPortraits`：诗人ID到图片URL的映射，仅用于时间轴人物。当前为空，先显示统一3:4图片占位；后续将上传图片通过import映射到对应ID即可替换，不影响顺序、数量或档案联动，不将其他章节头像自动当作正式时间轴插画。
- `journalPoets`：排行数据源，组件按数量排序取前五。占比的分母为当前榜单五人的数量总和。头像、姓名、数量、字号、诗风和引语均可替换。
- `journalExtraPoets`：只在时期图出现的人物，点击后也能展示右下档案；不参与前五排行统计。
- `works`：作品标题、诗句摘要、可选 `tag`、可选 `image`。支持任意数量；概览中按列展示，在代表作品页签中阅读。插画缺失时不自动生成。
- `profile`：可选 `hometown`、`biography`、`milestones`、`connections`、`achievements`、`status`。未提交的资料显示待补充，长内容在档案区域内滚动。
- `journalChronology.ts`：按搜韵公开接口的逐篇编号与原始标年汇总。全量索引核对7,245条，剔除词、辞赋、残句等225条，纳入诗歌7,020首；未标年、约年、区间及异说另列，缺失不作零创作。
- `journalProfiles.ts`：五人的字号、籍贯、生平、经历、交游与评价摘要，附正史及《唐诗大辞典》引录链接。出生地等有异说时保留说明。
- `journalPrimaryWorks.json`：每人三首代表作，提供采用版本的全文、原文链接及来源标年。诗歌正文为古代公版文本，不引入现代译注。
- `journalRankingSource`：汉语典诗词库。3,008 / 1,489 / 1,207 / 910 / 886 为该库收录口径，2026-10-21搜索索引再次核对，与热力图的搜韵诗歌口径独立，不以二者相减推算未系年数量。

完整来源快照、SHA256、统计清单与重建命令保存在 `artifacts/journal-research-20261021/`。`scripts/research-journal-chronology.mjs` 只读下载公开接口，`scripts/build-journal-chronology.mjs` 离线核验并生成发布数据。图表表示来源所标年的收录分布，不能当作诗人逐年实际创作总量。

## 交互与适配

点击或通过键盘操作圆环扇区可高亮对应类别；时期按钮显示对应数量；折线图诗人仅在图内高亮与吟诵，不联动右下档案；右下档案只由五人排行榜切换。档案保留概览、生平资料、代表作品三页签，取消重复的创作年谱页签，支持方向键切换。概览始终展示完整生涯；热力图保留单一 Tab 入口，左右键移动一年，上下键移动十年，Home/End 到首尾。选择年份后可展开逐首原文目录。

桌面宽度至少1200px且高度至少600px时，章节最小高度为屏幕高度减去导航栏的5.25rem，内容增多时随文档自然展开。左侧保留60–84px的竖排标题栏，其余区域中题材图占约39%、右侧模块占约61%，右侧上下约55:45。上方标题简化为“唐诗流变”，辅助信息收拢到同一行及来源脚注。折线使用ResizeObserver测量绘图区，以真实像素尺寸重新计算坐标，铺满可用宽高，不再将整张图限制到固定比例后缩在中间。排行姓名与数值保留16px；高度不超过850px时压缩面板间距、辅助文字；年谱一次展示全部年份，不设置内部滚动或分页，展开目录和传记时增加章节高度。手机标题横排，时间轴绘图区至少640px宽，时间轴保留自身横向浏览；年度网格适配宽度，完整显示，不横向滚动。

验证：`npm test`、`npm run build`，并检查 1672×900、1280×720 和 390px 手机视口。

题材诗句配置位于 themeVerses.ts，仅用于代表诗句联动，不改变统计分类。悬停120毫秒启动，移出模块复原；键盘聚焦立即展示，Escape清除，手机点击可开关。背景逐字雕刻动画支持减少动态效果设置。


概览以创作年谱为主体：人物信息收拢为头像、姓名、诗风、生卒年与字号摘要，代表作只显示最多三个标题入口，点击后切换到代表作品页签并展开相应诗句。年度网格、简洁图例、单行年份详情与统计口径采用紧凑布局；移除年代筛选、年龄切换、侧边详情卡及虚构时期条带。长内容由页面自然展开，不产生模块内滚动。

## 时间轴诗人及图片替换

时间轴精简为15位代表诗人，严格按采用的出生年份递增排序，同年仅相邻展示、不暗示年内先后：骆宾王（约619）、王勃（约650）、陈子昂（661）、孟浩然（689）、王维（约701）、李白（701）、杜甫（712）、韦应物（约737）、孟郊（751）、韩愈（768）、刘禹锡（772）、白居易（772）、杜牧（803）、李商隐（约813）、韦庄（836）。原有其他诗人档案继续保留，只减少时间轴入口。

人物使用618—907年共享线性年份坐标，不再按文学分期分组均分空间。单排图像卡在密集区保持28px中心间距，通过合并拥挤区间的平均位置最小化偏移；人物卡底部随折线高度起伏，短连接线吸附到采用生年对应的折线位置；细线终点仍是准确的采用生年坐标，悬停或聚焦可读到出生年份（约年明确标示）。出生时间与文学归属不同，例如杜牧出生于803年，文学归属仍为晚唐。四期曲线点放在相应时间区间中点；数量仍沿用林庚的分期总数，不能解释为中点年份的创作量。年份参照采用618/712/762/827/907这一种常见分界，不宣称分期没有其他方案，也不据此重算原统计。

人物统一使用3:4图片框及`object-fit: contain`。图片写入`journalPeriodPortraits`，例如`'wang-wei': wangWeiImage`；当前15位槽位及推荐文件名见`artifacts/tang-period-research-20261020/poet-portrait-slots.csv`。点击、Enter或Space联动档案；悬停/聚焦仍显示人物的文学分期统计。
